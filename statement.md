Problem statement
* Nowdays, we store many different types of files on our computers, such as photos,
  documents, videos, songs, programming files and many more. When all these files are kept
  together, it becomes difficult to find a particular file.

  The main goal of this project is to identify the type of a file using its extention
  and organise it into the correct category. This makes file management easier and helps
  users keep theri file arranged properly.


Scope of the project
* The Smart File Organiser is a simple python based project developed for learning
  purposes.
* This project can:
  * Accept file names from the user.
  * Check file extention such as, .jpg, .pdf, .mp3, .mp4 and .py
  * Classify files into different categories.
  * Display a final summary report.


  Target Users
  * Btech students
  * Beginners who are learning python.
  * Students working on mini projects.
  * Anyone who wants to understand basic file organisation concepts.


  High-level Features
  * File type detection- The program identifies the type of a file based on its extention.
  * File classification- Files are grouped into categories such as- images, documents, audios,
    videos, programming files and others.
  * File counting- The program keeps track of how many files belongs to each category.
  * Summary report- After processing all files, the program displays a report showing the
    total number of files and category wise count.


  Conclusion
  * Smart file organiser project helps organise files based on their extentions. It demonstrates
    the practical use of basic programming concepts while solving a common file management
    problem in an easy and systematic way.
